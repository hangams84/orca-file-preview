# File Preview for Orca

[![orca-compat](https://github.com/hangams84/orca-file-preview/actions/workflows/orca-compat.yml/badge.svg)](https://github.com/hangams84/orca-file-preview/actions/workflows/orca-compat.yml)

File Preview — плагин для [Orca](https://github.com/stablyai/orca), который позволяет прямо в Orca **просматривать в режиме только
для чтения** файлы Office, Hangul и PDF, текстовые файлы, изображения, 3D-модели, файлы САПР и проекты электроники. Работает
в настольной версии Orca (Windows · macOS · Linux), а также в браузерных и мобильных клиентах.

- Последний выпуск: **v0.4.0** · требуется Orca **1.4.248** или новее (для установки по Git URL — **1.4.252** или новее)
- Работает только в режиме `sandboxed-ui`: дополнительные разрешения (capabilities) не нужны, доступа к сети нет, ваши файлы
  никогда не изменяются.

обновление при изменении файла и поясняющее сообщение для повреждённых файлов.

### Текстовые форматы открываются сразу в предпросмотре (0.4.0)

Orca считает текстовыми файлы URDF, xacro, KiCad, draw.io, ASCII DXF, STEP/IGES/BREP, OBJ и другие текстовые 3D-форматы, а также
файлы `.doc`, сохранённые как RTF/HTML, и XML-файлы `.xls`. Плагин регистрирует для них отдельные текстовые редакторы, поэтому теперь
эти файлы по умолчанию открываются в предпросмотре. Однако файлы, которые Orca открывает сама (`.txt` `.csv` `.tsv` `.html` `.htm`),
по правилам Orca сначала открываются в режиме «Исходный текст»; чтобы увидеть предпросмотр, выберите «Предпросмотр» переключателем
режимов в правом верхнем углу вкладки.

### Сопутствующие файлы (📁 или перетаскивание)

Orca передаёт редактору только открытый файл. Выберите папку кнопкой 📁 на панели инструментов (с нажатой клавишей Shift — отдельные
файлы) или перетащите файлы на предпросмотр, и плагин прочитает их внутри своего изолированного фрейма:

| Предпросмотр | Что добавляют папка или перетащенные файлы |
| --- | --- |
| Робот (URDF/xacro) | Сетки (STL, DAE с текстурами, OBJ с `.mtl`, glTF) заменяют заглушки, положение сочленений сохраняется; `xacro:include` обрабатывается (`$(find pkg)`, относительные пути, вложенность) |
| 3D | Материалы и текстуры OBJ, внешние `.bin` и изображения glTF, текстуры DAE |
| Чертёж САПР (DXF) | Внешние ссылки (xref) вставляются как `XREF\|слой`, объекты IMAGE отрисовываются |
| KiCad | Переход по вложенным листам с позиционными обозначениями для каждого экземпляра, `.kicad_pro` → схема и плата, пользовательский `.kicad_wks` |
| SolidWorks | **3D-сборка** по сохранённому размещению компонентов (для файлов 2015 года и новее файлы деталей не нужны, для файлов 2014 года используются переданные детали) |
| EPLAN | Отрисовка макросов (`.ema` `.emp`, макросы внутри `.edz`); `.elk` + папка `.edb` → свойства проекта, страницы, список изделий |

### Панель File Preview

Откройте панель **File Preview** на правой боковой панели и воспользуйтесь кнопками «Open file…», «Open folder…» или перетаскиванием
(интерфейс плагина доступен только на корейском и английском). Файл отображается теми же рендерерами без ограничения редактора Orca
в 50 МБ (действуют только собственные ограничения рендереров — до 1 ГБ); можно открывать и файлы вне рабочего пространства. Файлы,
открытые вместе, используются как сопутствующие. Дополнительных разрешений панели не требуется.

## Установка

### (а) В приложении Orca (рекомендуется)

Требуется Orca **1.4.252** или новее.

1. Откройте **Настройки** → **Плагины**.
2. Выберите **Добавить плагин** → **По URL Git…**.
3. Вставьте `https://github.com/hangams84/orca-file-preview.git` в поле **URL репозитория с #ref** и нажмите **Продолжить** → **Установить**.
4. Проверьте разрешения, которые показывает Orca (только интерфейс в песочнице), и нажмите **Включить плагин**.

Пошаговое руководство со снимками экрана: [docs/install-guide/ru.md](docs/install-guide/ru.md)

### (б) Из командной строки

```sh
# Установить последнюю версию с GitHub (Orca 1.4.252+). Orca выведет запрашиваемый доступ и отпечаток для подтверждения.
orca plugin install https://github.com/hangams84/orca-file-preview
orca plugin install https://github.com/hangams84/orca-file-preview --approve <fingerprint>
# Конкретная версия: https://github.com/hangams84/orca-file-preview#v0.4.0

# Или из локальной папки
orca plugin install ./plugin
```

### (в) Пакеты выпуска, исполняемые файлы и скрипты

Скачайте их со страницы [GitHub Releases](https://github.com/hangams84/orca-file-preview/releases). На компьютере должна быть
установлена Orca 1.4.248 или новее, и её нужно хотя бы раз запустить; права администратора не нужны. Каждый установщик показывает
разрешения, которые запрашивает Orca, и одобряет их только после вашего подтверждения.

| ОС | Исполняемый файл | Скрипты (пакет zip или tar.gz) |
| --- | --- | --- |
| Windows 10/11 | `FilePreviewSetup-<версия>.exe` (меню: установка · обновление · удаление · состояние) | `installer\windows\install.cmd` |
| macOS | `File-Preview-Setup-<версия>-macos.zip` → *File Preview Setup.app* | `installer/macos/Install File Preview.command` |
| macOS · Linux | `sh file-preview-setup-<версия>.run [install\|update\|uninstall\|status]` | `sh installer/linux/install.sh` (Linux) |

Исполняемые файлы не подписаны. Если Windows SmartScreen блокирует запуск, выберите *Подробнее* → *Выполнить в любом случае*; в macOS,
чтобы обойти Gatekeeper, щёлкните файл, удерживая клавишу Control, и выберите *Открыть*. В Orca 1.4.248–1.4.251 нет команды
`plugin install`, поэтому установщики регистрируют папку как плагин в режиме разработки (`plugin dev load`); в этом случае не удаляйте
папку. В Windows 7/8 установщик отказывается от установки и выводит поясняющее сообщение: Orca требует Windows 10 или новее.
Все параметры: [installer/README.md](installer/README.md)

### (г) Обновление и удаление

- **Установлено из приложения Orca или через CLI**: узнайте ключ плагина командой `orca plugin list`, затем обновите его командой
  `orca plugin update <ключ>` и удалите командой `orca plugin uninstall <ключ>`. При обновлении плагин, установленный по Git URL,
  переходит на последний тег версии.
- **Исполняемые файлы**: меню `FilePreviewSetup-<версия>.exe` (или `/update` · `/uninstall`), `file-preview-setup-<версия>.run update|uninstall`
  либо *File Preview Setup.app* в macOS.
- **Скрипты**: Windows `installer\windows\update.cmd` · `uninstall.cmd`, macOS `Update File Preview.command` ·
  `Uninstall File Preview.command`, Linux `sh installer/linux/update.sh` · `sh installer/linux/uninstall.sh`.
- Обновление проверяет последний выпуск этого репозитория на GitHub, скачивает пакет, сверяет SHA-256 и после вашего подтверждения
  переустанавливает плагин. Одна предыдущая версия сохраняется. `--check` (в Windows — `-Check`) только проверяет наличие обновления.

## Ограничения

- **Ограничение чтения в 50 МБ**: Orca передаёт редактору плагина не более 50 МБ данных файла (кроме изображений и PDF; плагин не может
  это изменить, см. [stablyai/orca#46775](https://github.com/stablyai/orca/issues/46775)). Сам плагин принимает файлы до 1 ГБ. Файлы
  большего размера открывайте в [панели File Preview](#панель-file-preview). Файлы STEP можно также сжать gzip и открыть как `.stpz`
  (обычно STEP уменьшается в 5–8 раз): `gzip -c model.step > model.stpz`.
- **Предельный размер для движка САПР**: OpenCascade (32-битный WebAssembly, до 4 ГБ памяти) на практике справляется с исходными
  файлами STEP примерно до 200 МБ. Замеры на синтетических сборках с большим числом деталей: 61 МБ — 1,5 мин · 189 МБ — 14 мин ·
  343 МБ — не укладывается в 30 мин · 412 МБ — не хватает памяти.
- **Форматы, которые сначала открываются в режиме «Исходный текст»**: `.txt` `.csv` `.tsv` `.html` `.htm` Orca открывает сама, поэтому
  первым появляется режим «Исходный текст». Предпросмотр выбирается переключателем режимов.
- **Что не отрисовывается**:
  - EPLAN: страницы схем (собственное двоичное хранилище объектов EPLAN, `.eod`/`.eox`) и графика библиотек символов.
  - SolidWorks: точная B-rep-геометрия и виды чертежей не перерисовываются, вместо них показываются сохранённые изображения. Скрытые и
    погашенные компоненты перечисляются в списке, но не отрисовываются.
  - draw.io: библиотеки трафаретов, не встроенные в плагин (`mxgraph.aws4.*` и др.), показываются пунктирной рамкой с именем трафарета,
    внешние (сетевые) изображения — заглушкой.
  - Visio: формулы не вычисляются (используются сохранённые значения). Двоичный формат `.vsd` не поддерживается (выводится поясняющее сообщение).
  - DWF: для листа с командами рисования, которые модуль чтения не поддерживает, показывается сохранённая в пакете миниатюра с предупреждением.
  - DWG (отдельный плагин): 3D-тела и области (ACIS), содержимое растровых изображений, OLE-объекты и xref не отрисовываются, а
    перечисляются в примечании.
  - Office: диаграммы и SmartArt в PPTX и стили ячеек на листах упрощаются; в электронных таблицах показываются первые 20 000 строк.
    Формулы, диаграммы и OLE-объекты в `.hwp` отображаются рамками с подписью.
- Мобильные клиенты проверялись в браузерном тестовом стенде (профили телефона, WebKit, режим старого движка), а не на реальных устройствах.

## Совместимость

Orca **1.4.248** или новее; для установки по Git URL — **1.4.252** или новее. CI совместимости с нуля устанавливает каждый выпуск Orca
в Ubuntu, macOS и Windows, затем устанавливает и тестирует плагин. Таблица результатов ведётся только в одном месте — в корейском README:
[Совместимость с Orca (CI)](README.md#ci-matrix). Подтверждающие материалы по платформам: `docs/evidence/platforms/`.

## Разработка

```sh
npm ci
npm run vendor            # собрать сторонние библиотеки в plugin/vendor
orca plugin dev load plugin --approve <fingerprint>
npm run typecheck
node tools/harness/run.mjs --only docx,pdf --profiles desktop-dark,mobile-light
node tools/verify.mjs --round <n> && node tools/build-docs.mjs
node tools/check-readmes.mjs   # проверить строку языков, ссылки и таблицу форматов во всех 11 README
```
