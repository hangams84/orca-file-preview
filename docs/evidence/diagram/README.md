# Diagram Preview — fidelity evidence

**What:** the new Diagram Preview editor (draw.io `.drawio`/`.dio`, Visio `.vsdx`/`.vsdm`/`.vstx`/`.vssx`) on a corpus
generated by `tools/make-diagram-samples.py` (`samples/diagram/*`, `samples/sample.*`), compared with a reference.

**References**
- **draw.io:** the official draw.io viewer (`viewer-static.min.js` v24.7.17, Apache-2.0), fetched to `.orca/drawio/` (not
  committed) and run *without* the plugin CSP in the same Chromium.
- **Visio:** Microsoft Visio is not installed on this machine (Office is; `Visio.InvisibleApp` COM is not registered), so
  the second opinion is **LibreOffice 26.8.2 (libvisio)**: `.vsdx` → PDF → PNG at 96 dpi (`tools/diagram/visio-truth.py`).
  LibreOffice is itself an approximation of Visio; where the two disagree the table says which reading we follow and why.

**How measured** (`node tools/diagram/fidelity.mjs`, then `python tools/diagram/compose.py docs/evidence/diagram`):
our render is captured through the browser harness (Orca-like CSP, light theme, 100 %, 1800×1400), one PNG per page in
`ours/`; references in `truth/`; side-by-side images in `compare/` (left reference, right File Preview). The score is a
rough grey-level similarity of the two drawings cropped to their content and scaled to the same size (100 = identical);
the verdict column comes from looking at the pair.

## Not drawn / limits

- draw.io stencil libraries (`mxgraph.aws4.*`, `mxgraph.cisco.*`, …) are not bundled: each shows as a dashed box named
  after the stencil, plus its label. Remote pictures (http/https) show a named placeholder; `data:` pictures draw.
- draw.io math (`math=1`), sketch style, glass effect, custom `<shape>`-stencils inside styles and Mermaid/PlantUML cells
  draw as plain shapes. Orthogonal routing is a compact heuristic, not mxGraph's full router; it matches on the corpus.
- Visio: formulas are not evaluated (the stored values are used, as Visio writes them); fill patterns beyond hatches are
  approximated; arrow heads are approximated by kind and size; layers' visibility/print flags, comments, data graphics,
  container/list behaviour and `.vsd` (binary) are not supported (`.vsd` gets a clear message).

## Official draw.io viewer under the plugin CSP

`csp-check.json`: the viewer (3.59 MB, 7 `eval(` sites) loaded from the harness server **did** draw a one-shape probe
under the Orca-like CSP, with one refusal (it fetches `viewer.diagrams.net/math/...`). It was not shipped because it is
3.6 MB of script for one format, fetches math, fonts and stencil libraries over the network (none available in Orca's
frames), injects `<style>` elements (a renderer `<style>` was seen not to take effect in Orca frames, see `media/image-view.ts`) and evaluates code for
unregistered styles. The in-tree renderer is ~140 KB of TypeScript for draw.io and Visio together.
