# 3D and CAD fixtures: sources and licences

All files below are generated by this repository's own scripts from geometry they construct; no third-party model
data is included, so they are covered by the repository licence (MIT).

- `tools/make-3d-samples.mjs` (Node, three.js geometry generators, hand-written writers; Draco via three's encoder,
  meshopt via the `meshoptimizer` encoder): STL, OBJ, PLY, OFF, glTF/GLB, 3MF, FBX, COLLADA.
- `tools/make-cad-samples.py` (OpenCascade 8.0 through `cadquery-ocp`, used only to write the files): STEP, IGES, BREP.
  `--perf` writes `samples/perf/large-assembly.step` (git-ignored, about 17 MB).
