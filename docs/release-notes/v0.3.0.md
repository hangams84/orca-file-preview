## 0.3.0 변경 사항 / What changed

새 형식 뷰어 6종과 Ubuntu 26.04 CI를 추가했습니다. / Six new viewers and an Ubuntu 26.04 CI column.
실제 Orca 1.4.263 확인 / Checked in real Orca 1.4.263: [`docs/evidence/v0.3.0`](https://github.com/hangams84/orca-file-preview/tree/main/docs/evidence/v0.3.0).

| 뷰어 / Viewer | 확장자 / Extensions | 내용 / What it shows |
| --- | --- | --- |
| **CAD Drawing Preview** | `.dxf` `.dwf` `.dwfx` | Drawings with layers, model space and layouts, blocks, dimensions, hatches and Korean text. DXF can be ASCII or binary (R12–2018+); DWF reads W2D streams and falls back to the sheet thumbnail with a notice; DWFx reads XPS pages with embedded fonts. DXF geometry matches ezdxf at 99.5–100 %. |
| **Diagram Preview** | `.drawio` `.dio` `.vsdx` `.vsdm` `.vstx` `.vssx` | Pages, shapes, connectors, text, pictures and links. draw.io scores 90–99 against the official viewer; Visio scores 87–99 against LibreOffice. |
| **KiCad Preview** | `.kicad_sch` `.kicad_pcb` `.kicad_mod` `.kicad_sym` `.kicad_pro` | Schematics, boards (layer toggles, flip, net hover), footprints, symbols and a project summary. Scores 79–100 % against kicad-cli. |
| **Robot Preview** | `.urdf` `.xacro` | ROS 2 robots in 3D, with joint sliders, mimic joints and visual/collision/frame toggles. The xacro processor's output is identical to PyPI xacro 2.1.1. |
| **SolidWorks Preview** | `.sldprt` `.sldasm` `.slddrw` `.slddrt` `.prtdot` `.asmdot` `.drwdot` | Stored preview pictures, properties, configurations and references. Parts show their saved display mesh in 3D. |
| **EPLAN Preview** | `.edz` `.zw1` `.elk` `.ell` `.elr` `.els` `.elp` `.elx` `.ela` `.zx1` | EDZ part data, pictures and PDFs; project properties and page descriptions. Schematic pages are not drawn, and every page says so. |

- **AutoCAD `.dwg` / `.dwt`** ship as a separate GPL-3.0 plugin, **[File Preview DWG](https://github.com/hangams84/orca-file-preview-dwg)** v0.1.0. Install it from the Git URL `https://github.com/hangams84/orca-file-preview-dwg.git`.
- **Orca compatibility CI** adds Ubuntu 26.04 (Orca 1.4.248, 1.4.253, 1.4.258 and 1.4.277) and runs Orca 1.4.277 on every OS.
- **Source view first:** ASCII DXF, draw.io, KiCad, URDF and xacro are text files, so Orca opens them in its Source view first. Pick the preview with the view toggle at the tab's top right.
- **Not shown, by design:** files outside the opened one (URDF meshes, xacro includes, DXF xrefs). An editor receives only the file it opens, so these show as labelled placeholders.

Read-only previews of Office, Hangul (HWP/HWPX), PDF, text, table, HTML, image and 3D model files inside [Orca](https://github.com/stablyai/orca) — desktop (Windows · macOS · Linux) and browser/mobile clients.

| --- | --- | --- |
| Windows 10/11 | `FilePreviewSetup-0.3.0.exe` (메뉴: 설치 · 업데이트 · 제거 · 상태 / `/install /update /uninstall /status /yes`) | `orca-file-preview-0.3.0.zip` → `installer\windows\install.cmd` · `update.cmd` · `uninstall.cmd` |
| macOS | `File-Preview-Setup-0.3.0-macos.zip` → *File Preview Setup.app* (first open: Control-click → Open) | `file-preview-setup-0.3.0.run` or `orca-file-preview-0.3.0.tar.gz` → `installer/macos/*.command` |
| Linux | `sh file-preview-setup-0.3.0.run [install\|update\|uninstall\|status]` | `orca-file-preview-0.3.0.tar.gz` → `installer/linux/{install,update,uninstall}.sh` |

Every installer shows the access Orca asks you to approve and approves only after you confirm. **Update** checks this repository's latest release, downloads it, verifies the SHA-256 and reinstalls (`update --check` only reports). Orca 1.4.248–1.4.251 have no `plugin install`, so the folder is registered with `plugin dev load` there. Windows 7/8 are refused with a clear message (Orca needs Windows 10+). The executables are unsigned: Windows SmartScreen → *More info* → *Run anyway*; macOS Gatekeeper → Control-click → *Open*.

Without the packages: `orca plugin install https://github.com/hangams84/orca-file-preview` (newest release) or `https://github.com/hangams84/orca-file-preview#v0.3.0`, or paste `https://github.com/hangams84/orca-file-preview.git` in Orca → Settings → Plugins → Install → Git URL (Orca 1.4.252+).

## Known limitations

- Orca opens `.txt .csv .tsv .log .html .svg` (and text-like files) in its own Source view first: pick the preview with the view toggle at the tab's top right.
- Office rendering is a preview, not Office: charts/SmartArt in PPTX and cell styles in sheets are simplified; spreadsheets show the first 20,000 rows; .hwp equations/charts/OLE objects show as labelled boxes; 3D glTF with external .bin/textures and meshopt compression is not supported (no network).
- File size: Orca hands a plugin editor at most 50 MB (images and PDFs excepted; stablyai/orca#46775). The plugin itself accepts up to 1 GB; compress large STEP files to `.stpz` (gzip). The CAD engine (32-bit WebAssembly, 4 GB) is practical up to roughly 200 MB of STEP (measured: 189 MB in 14 min; 343 MB exceeds the time limit; 412 MB runs out of memory).
- Tested on real Orca for Windows 11, Ubuntu 22.04/24.04 and macOS 15; mobile clients were tested through the browser harness (phone profiles, WebKit, older-engine mode), not on physical devices.
