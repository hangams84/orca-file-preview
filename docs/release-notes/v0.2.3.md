## 0.2.3 변경 사항 / What changed

- **STEP · IGES · BREP가 Orca에서 열리지 않던 문제 수정 / CAD files now open in Orca**: the OpenCascade engine was
  started from a `blob:` script, which Orca's plugin frames refuse (`preview refused: cad-engine`). It now ships as a
  plugin file (`vendor/occt/occt-import-js.csp.js`, an LGPL-noted modified copy beside the unmodified library). The test
  harness refuses `blob:` scripts like Orca. Verified in Orca 1.4.258: a STEP assembly and an IGES part render.
  CAD files are text files, so Orca opens them in its Source view first: pick the preview with the view toggle.
- **PPTX 사진이 형식·효과에 따라 보이지 않던 문제 수정 / Pictures in slides**: checked against PowerPoint's own slide
  export on a 49-case corpus built with PowerPoint — 31 → 46 match, 6 → 0 missing.
  - Now shown: TIFF (LZW, multipage), EMF, WMF.
  - EXIF-rotated JPEGs are no longer rotated twice.
  - Recolour (grayscale, black-and-white, washout, duotone), brightness/contrast, transparency and "set transparent
    colour" are applied; shape picture fills (stretch, tile) and pictures in table cells are drawn.
  - Pictures above 16 MP are decoded within a size budget; HEIC / JPEG XR show a named placeholder.
  - Remaining differences, by design: ICO (PowerPoint cannot display it; the preview does), linked pictures (path
    placeholder, no file access), CMYK JPEG (PowerPoint applies a press profile).
- The same picture decoder improves Word and legacy files: `.docx` 9/14 → 14/14, `.doc` 9/12 → 12/12, `.ppt` 19/23 → 22/23.
- CI: Linux images cache the shared Ubuntu layers; stalled downloads fail and retry.

---

Read-only previews of Office, Hangul (HWP/HWPX), PDF, text, table, HTML, image and 3D model files inside [Orca](https://github.com/stablyai/orca) — desktop (Windows · macOS · Linux) and browser/mobile clients.
Orca 안에서 Office · 한글(HWP/HWPX) · PDF · 텍스트 · 표 · HTML · 이미지 · 3D 모델 파일을 읽기 전용으로 미리보기 하는 플러그인입니다.

## 지원 형식 / Formats

**Word Preview** `.docx` `.doc` · **Slides Preview** `.pptx` `.ppt` · **Sheet Preview** `.xlsx` `.xlsm` `.xls` `.ods` · **PDF Preview** `.pdf` · **Image Preview** `.gif` `.bmp` `.svg` · **HTML Preview** `.html` `.htm` `.xhtml` · **Table Preview** `.csv` `.tsv` · **Hangul Preview** `.hwp` `.hwpx` · **Text Preview** `.txt` `.log` · **3D Preview** `.stl` `.obj` `.ply` `.glb` `.gltf` `.3mf` `.off` `.fbx` `.dae` `.step` `.stp` `.iges` `.igs` `.brep`

- Requires Orca **1.4.248+** · execution `sandboxed-ui` only (no extra capabilities, no network, never edits files)
- Korean/English UI, dark/light theme, zoom (Ctrl+wheel, pinch, buttons), phone-width layouts, EUC-KR detection, safe HTML/SVG (scripts never run)

Every installer shows the access Orca asks you to approve and approves only after you confirm. **Update** checks this repository's latest release, downloads it, verifies the SHA-256 and reinstalls (`update --check` only reports). Orca 1.4.248–1.4.251 have no `plugin install`, so the folder is registered with `plugin dev load` there. Windows 7/8 are refused with a clear message (Orca needs Windows 10+). The executables are unsigned: Windows SmartScreen → *More info* → *Run anyway*; macOS Gatekeeper → Control-click → *Open*.

Without the packages: `orca plugin install https://github.com/hangams84/orca-file-preview` (newest release) or `https://github.com/hangams84/orca-file-preview#v0.2.3`, or paste `https://github.com/hangams84/orca-file-preview.git` in Orca → Settings → Plugins → Install → Git URL (Orca 1.4.252+).

## Known limitations

- Orca opens `.txt .csv .tsv .log .html .svg` (and text-like files) in its own Source view first: pick the preview with the view toggle at the tab's top right.
- Office rendering is a preview, not Office: charts/SmartArt in PPTX and cell styles in sheets are simplified; spreadsheets show the first 20,000 rows; .hwp equations/charts/OLE objects show as labelled boxes; 3D glTF with external .bin/textures and meshopt compression is not supported (no network).
- Tested on real Orca for Windows 11, Ubuntu 22.04/24.04 and macOS 15; mobile clients were tested through the browser harness (phone profiles, WebKit, older-engine mode), not on physical devices.
