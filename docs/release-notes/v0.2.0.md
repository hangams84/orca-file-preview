Read-only previews of Office, Hangul (HWP/HWPX), PDF, text, table, HTML, image and 3D model files inside [Orca](https://github.com/stablyai/orca) — desktop (Windows · macOS · Linux) and browser/mobile clients.
Orca 안에서 Office · 한글(HWP/HWPX) · PDF · 텍스트 · 표 · HTML · 이미지 · 3D 모델 파일을 읽기 전용으로 미리보기 하는 플러그인입니다.

## 지원 형식 / Formats

**Word Preview** `.docx` `.doc` · **Slides Preview** `.pptx` `.ppt` · **Sheet Preview** `.xlsx` `.xlsm` `.xls` `.ods` · **PDF Preview** `.pdf` · **Image Preview** `.gif` `.bmp` `.svg` · **HTML Preview** `.html` `.htm` `.xhtml` · **Table Preview** `.csv` `.tsv` · **Hangul Preview** `.hwp` `.hwpx` · **Text Preview** `.txt` `.log` · **3D Preview** `.stl` `.obj` `.ply` `.glb` `.gltf` `.3mf` `.off` `.fbx` `.dae`

- Requires Orca **1.4.248+** · execution `sandboxed-ui` only (no extra capabilities, no network, never edits files)
- Korean/English UI, dark/light theme, zoom (Ctrl+wheel, pinch, buttons), phone-width layouts, EUC-KR detection, safe HTML/SVG (scripts never run)

## 설치 / Install

| OS | 실행 파일 / Executable | 스크립트 패키지 / Script package |
| --- | --- | --- |
| Windows 10/11 | `FilePreviewSetup-0.2.0.exe` (메뉴: 설치 · 업데이트 · 제거 · 상태 / `/install /update /uninstall /status /yes`) | `orca-file-preview-0.2.0.zip` → `installer\windows\install.cmd` · `update.cmd` · `uninstall.cmd` |
| macOS | `File-Preview-Setup-0.2.0-macos.zip` → *File Preview Setup.app* (first open: Control-click → Open) | `file-preview-setup-0.2.0.run` or `orca-file-preview-0.2.0.tar.gz` → `installer/macos/*.command` |
| Linux | `sh file-preview-setup-0.2.0.run [install\|update\|uninstall\|status]` | `orca-file-preview-0.2.0.tar.gz` → `installer/linux/{install,update,uninstall}.sh` |

Every installer shows the access Orca asks you to approve and approves only after you confirm. **Update** checks this repository's latest release, downloads it, verifies the SHA-256 and reinstalls (`update --check` only reports). Orca 1.4.248–1.4.251 have no `plugin install`, so the folder is registered with `plugin dev load` there. Windows 7/8 are refused with a clear message (Orca needs Windows 10+). The executables are unsigned: Windows SmartScreen → *More info* → *Run anyway*; macOS Gatekeeper → Control-click → *Open*.

Without the packages: `orca plugin install https://github.com/hangams84/orca-file-preview/tree/v0.2.0/plugin` (Orca 1.4.252+).

## Known limitations

- Orca opens `.txt .csv .tsv .log .html .svg` (and text-like files) in its own Source view first: pick the preview with the view toggle at the tab's top right.
- Office rendering is a preview, not Office: charts/SmartArt in PPTX and cell styles in sheets are simplified; spreadsheets show the first 20,000 rows; .hwp equations/charts/OLE objects show as labelled boxes; 3D glTF with external .bin/textures and meshopt compression is not supported (no network).
- Tested on real Orca for Windows 11, Ubuntu 22.04/24.04 and macOS 15; mobile clients were tested through the browser harness (phone profiles, WebKit, older-engine mode), not on physical devices.
