## 0.5.0 변경 사항 / What changed

### AI 모델 시각화 / AI model visualization
PyTorch (`.pt` `.pth` `.ckpt` `.chkpt` `.pt2` `.ptl`, TorchScript, Lightning, Hugging Face), `.safetensors`, ONNX, TFLite,
GGUF, Keras (`.keras` `.h5`) and NumPy (`.npy` `.npz`) open in **AI Model Preview**. You switch between seven views
in the toolbar:

| 보기 / View | 내용 / What it shows |
| --- | --- |
| Graph | Operator graph (TorchScript, `.pt2`, ONNX, TFLite, Keras), with collapsible modules, direction, minimap and search |
| Tree | Module hierarchy with parameter count, size and dtype per module |
| Table | Every tensor: name, type, shape, dtype, params, bytes; sortable, filterable, CSV copy |
| Map | Treemap of the parameter share by module |
| Architecture | Block diagram inferred from names and shapes, marked as inferred |
| Tensor | Statistics, histogram, weight heatmap and conv-kernel grid of a selected tensor |
| Info | Epoch/step, hyper-parameters, optimizer, schedulers, metadata |

Export: SVG/PNG of the view, JSON/Markdown summary.

- **Safety:** pickles are read by an inert VM. No code in a model file ever runs; a malicious pickle shows a
  warning.
- **Fidelity:** parameter totals match PyTorch on 39/39 generated models. The other formats match their Python
  libraries on 1,457/1,457 checks.
- **Large models:** Orca hands an editor at most 50 MB, so open big checkpoints from the **File Preview panel**. It
  reads only the parts it needs: a 1.71 GB GPT checkpoint opens in about 0.16 s after reading 0.11 MB. The panel
  also recognises `.bin` and `.pkl` model files by their content.
- Research and design notes: [`docs/research/ai-model-visualization.md`](https://github.com/hangams84/orca-file-preview/blob/main/docs/research/ai-model-visualization.md).

## Known limitations

- Files Orca opens itself (`.txt .csv .tsv .html .htm`) open in its Source view first: pick the preview with the view toggle at the tab's top right. Other text formats (URDF, xacro, KiCad, draw.io, DXF, STEP, OBJ …) open in the preview directly.
- Office rendering is a preview, not Office: charts/SmartArt in PPTX and cell styles in sheets are simplified; spreadsheets show the first 20,000 rows; .hwp equations/charts/OLE objects show as labelled boxes; 3D glTF with external .bin/textures and meshopt compression is not supported (no network).
- File size: Orca hands a plugin editor at most 50 MB (images and PDFs excepted; stablyai/orca#46775). The plugin itself accepts up to 1 GB; compress large STEP files to `.stpz` (gzip). The CAD engine (32-bit WebAssembly, 4 GB) is practical up to roughly 200 MB of STEP (measured: 189 MB in 14 min; 343 MB exceeds the time limit; 412 MB runs out of memory).
- Tested on real Orca for Windows 11, Ubuntu 22.04/24.04 and macOS 15; mobile clients were tested through the browser harness (phone profiles, WebKit, older-engine mode), not on physical devices.
